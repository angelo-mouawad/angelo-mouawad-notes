# My Notes

A personal knowledge base and notes collection. For the best experience, open this repo as an Obsidian vault, links, tags, and graph view will all work correctly.


## Getting started

1. **Fork or clone this repo**
   `git clone https://github.com/your-username/your-notes-repo.git`

3. **Download Obsidian**
   Get the free app at [obsidian.md](https://obsidian.md) available for Windows, macOS, Linux, iOS, and Android.

4. **Open the folder as a vault**
   Launch Obsidian → click **Open folder as vault** → select the folder you just cloned.

> 💡 **Tip:** Don't open individual `.md` files directly, open the whole folder as a vault so Obsidian can resolve internal links and render the graph correctly.


## Structure

Feel free to browse the notes in any markdown editor, but some features (backlinks, graph view, tags) are Obsidian-specific.
