# What Is Java ?

**Java** is a programming language **and** a platform. Unlike Python or JavaScript, Java is **compiled**, meaning your code is turned into a format the computer can run.

To run Java programs, you need the **Java Development Kit (JDK)**, which includes.
- **Java compiler `javac`** → Converts your code to bytecode.
- **Java runtime `java`** → Runs the compiled bytecode.

Install the Java Development Kit by going to [Oracle JDK](https://www.oracle.com/java/technologies/javase/jdk-downloads.html) or [OpenJDK](https://openjdk.org) for a free version. The java package manager is `java` and the java compiler package manager is `javac`.
